## 3. Database CmsMediaAsset Registrations

All media assets stored under `/uploads/` are registered in the PostgreSQL `CmsMediaAsset` table:
```sql
SELECT id, filename, folder, mime_type, size_bytes, width, height, alt_text 
FROM cms_media_assets 
ORDER BY folder, filename;
```
- Total active records: **16 assets**
- Searchable folders: `home`, `about`, `programmes`, `sponsorship`, `partnerships`, `children`, `placeholders`, `general`.
- Editable via Admin CMS: `/admin/website/media`
